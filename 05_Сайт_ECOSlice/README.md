# Сайт ECOSlice: премиальный бренд + AI-обработка заявок

Сайт для бренда изделий из можжевельника (Tilda) с автоматической обработкой заявок.

**Стек:** Tilda, Make, Google Sheets, Notion, Perplexity AI, Telegram.
**Результат:** работающий сайт и полностью автоматизированная обработка заявок с AI-анализом.

**Файлы:**
- `01_Описание_проекта.pdf` — задача и вклад.
- `02_Скриншоты_сайта.pdf` — главный экран, галерея, контакты.
- `03_Схема_автоматизации.pdf` — схема Make и результат AI-анализа.
