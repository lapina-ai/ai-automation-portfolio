# Flask: ML + LLM

Веб-приложение на Flask, объединяющее классическое машинное обучение (ML) и генеративный ИИ (LLM) через OpenRouter API.

**Стек:** Python 3.11, Flask, Requests, OpenRouter API (DeepSeek), HTML/CSS.
**Результат:** работающее приложение с рекомендациями фильмов и генератором бизнес-идей. Исправлены ошибки API (404, 401), ключи вынесены в `.env`.

**Файлы:**
- `01_Описание_проекта.pdf` — задача, стек, вклад.
- `02_Архитектура_и_схема.pdf` — схема данных.
- `03_Скриншоты_интерфейса.pdf` — работающие экраны.
