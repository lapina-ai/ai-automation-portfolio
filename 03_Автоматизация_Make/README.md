# Автоматизация договоров и AI-анализ отзывов

Два сценария в Make для исключения ручного труда: подготовка договоров для самозанятых и анализ отзывов клиентов.

**Стек:** Make (ex-Integromat), Google Forms, Google Docs, Perplexity AI, Notion, Gmail, Telegram.
**Результат:** полностью автоматизированный цикл (от формы до PDF) и автоматическая оценка тональности отзывов (CSAT/NPS).

**Файлы:**
- `01_Описание_проекта.pdf` — задача и вклад.
- `02_Схема_сценария.pdf` — схемы процессов.
- `03_Скриншоты_результатов.pdf` — работающие сценарии и результаты.
