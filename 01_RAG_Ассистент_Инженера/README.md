# RAG-Ассистент Инженера

Корпоративная RAG-платформа (On-Premise) для поиска по технической документации и журналам обслуживания станков (HAAS VF-2, TRUMPF TruLaser 3030).

**Стек:** n8n, Qdrant, LM Studio (Mistral-7B), Docker, Python (Flask).
**Результат:** время поиска информации сокращено с 15 минут до 1 минуты. Точность ответов — 95%.

**Файлы:**
- `01_Описание_проекта.pdf` — задача, цель, стек.
- `02_Архитектура_и_схема.pdf` — схема системы и 8 workflow.
- `03_Тестирование_и_результаты.pdf` — метрики и тесты.
- `04_Инструкция_пользователя.pdf` — как работать с интерфейсом.
### Код интерфейса и живое демо

В папке находится файл `index.html` — это веб-интерфейс для RAG-ассистента (HTML/CSS/JS).

**Функции интерфейса:**
- Выбор станка (HAAS VF-2 или TRUMPF TruLaser 3030).
- Выбор типа документа (коды ошибок, инструкции, сертификаты).
- Ввод вопроса и получение ответа от ИИ.
- Вкладка «Журнал учёта» для добавления поломок и осмотров.
- Вкладка «Документация» для редактирования файлов.
