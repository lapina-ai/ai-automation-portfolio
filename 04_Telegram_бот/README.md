# Telegram-бот для обработки обращений

Бот для автоматизации сбора обращений (ошибки и предложения) с записью в Notion.

**Стек:** Make (ex-Integromat), Telegram Bot API, Notion.
**Результат:** автоматизированная обработка, ветвление (fallback), автоматическое обновление статуса в Notion (complete).

**Файлы:**
- `01_Описание_проекта.pdf` — задача и логика.
- `02_Схема_сценария.pdf` — схема в Make.
- `03_Скриншоты_диалога.pdf` — примеры диалогов и таблица Notion.
